# Ejecución de la validación con el equipo

Estado: protocolo preparado; los resultados humanos se completan después de observar la tarea. Las doce actas `IHC-A-XX-sesion.md` conservan los campos de registro. No se asigna una persona, fecha, cita o resultado que no haya sido confirmado.

## Preparar la sesión

1. Servir el repositorio con `python -m http.server 8000` y anotar el commit utilizado.
2. Abrir v1 o v2, seleccionar la tarjeta y usar un perfil separado de las pruebas técnicas. Para una sesión nueva A08/A12, usar Iniciar nueva sesión tras un cierre o un perfil limpio; no eliminar una sesión que se esté evaluando para reanudación.
3. Trabajar a 360 x 800 para las restricciones móviles. Registrar ancho real, zoom, navegador, sistema operativo y dispositivo.
4. Invitar a una persona de otro equipo, obtener su consentimiento y usar un código P-001 a P-999. No publicar nombres, cédulas ni grabaciones sin autorización.
5. Entregar únicamente la consigna de la tarjeta. El observador no señala botones ni completa pasos. Si se da ayuda, registrar cuándo y cuál; la tarea ya no se clasifica como finalizada sin ayuda.
6. Iniciar el cronómetro cuando la persona empieza a actuar. Detenerlo al lograr el objetivo, abandonar o alcanzar el límite establecido. A01 tiene el límite de tres minutos; para las demás tarjetas registrar el criterio acordado, sin atribuir a la guía un límite adicional.

## Registro consistente

- **Tiempo:** inicio y fin reales, duración en segundos y causa de detención. Una captura aislada no demuestra el tiempo total.
- **Error:** acción que impide o desvía el objetivo; describir pantalla, acción, consecuencia y recuperación. No contar dos veces el mismo evento sin explicar la regla.
- **Pausa:** segundo de inicio, duración aproximada, pantalla y comportamiento observado. No inferir emociones a partir de una pausa sin otra evidencia.
- **Resultado:** completada sin ayuda, con ayuda, incompleta o abandonada.
- **Cita:** transcribir solo lo escuchado, indicando el momento. Si no hubo cita, registrar «no se recogió cita».
- **Evidencia:** guardar capturas o grabaciones de esa sesión con código anónimo, versión, tarjeta y momento. Mantener las capturas automáticas identificadas como técnicas.

## Comparar v1 y v2

Registrar si participa la misma persona y el orden de las versiones. Cuando sea posible, alternar el orden entre participantes y explicar el posible aprendizaje. Reportar diferencias de tiempo y errores solo cuando ambas mediciones existan. Una sola persona no permite generalizar la mejora.

Las cantidades de CaféU difieren entre versiones: v1 usa café 1,50 y sánduche 2,25; v2 usa 1,50 y 2,75. Juzgar si el total corresponde al catálogo de cada versión, no si ambas tienen el mismo precio.
