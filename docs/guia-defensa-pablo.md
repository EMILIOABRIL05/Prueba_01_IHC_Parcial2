# Guía de estudio del prototipo v2

El aporte base de Pablo está en PR #12. Esta guía se actualiza para corresponder con las correcciones posteriores: Cancelar es el foco inicial del modal; la revisión del importe se invalida ante toda mutación; los validadores de Dashboard son comunes; el cierre no se confirma si el guardado obligatorio falla.

Consultar [decisiones](decisiones.md), [colaboración](colaboracion.md) y [ejecución actual](../evidencias/ejecucion-actual/README.md). Las curvas son estimaciones; las capturas actuales son automatización de navegador; los registros humanos están pendientes de confirmación según [pruebas/sesion.md](../pruebas/sesion.md).

La guía general explica la actualización comunicada sobre defensa oral. No se atribuye una defensa ni un ensayo humano que no se haya realizado.
