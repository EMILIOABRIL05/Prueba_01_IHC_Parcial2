# Respuesta a incidencia nueva · completar durante la prueba

**No se incluyen respuestas reservadas del documento docente.** Completar al recibir oficialmente el cambio.

1. Incidente recibido a las [hora real]; descripción textual [sin copiar información reservada antes de la entrega].
2. Crear Issue con responsable, impacto, pasos para reproducir, aceptación y prioridad.
3. Cambiar un requisito Rxx y conservar historial de modificación.
4. Actualizar una rama del flujo y su referencia a la pantalla/componente.
5. Implementar y probar el cambio; registrar condiciones normal/error/accesibilidad.
6. Hacer commit **posterior** a la entrega, abrir PR y solicitar revisión fundamentada.
7. Adjuntar evidencia observable y explicar en vivo qué se cambió.
