# Capturas históricas aportadas

Estas imágenes se conservan sin modificación de bytes. Representan una interfaz anterior, no el código de la rama actual ni la ejecución de participantes. `procedencia.json` registra ubicación previa, archivo conservado y SHA-256.

Las copias A12 del fallo y de la solución coinciden con las capturas técnicas de base. La imagen v2 incluye una nota de ejemplo y no acredita una sesión humana. Las capturas nuevas están en [ejecucion-actual](../ejecucion-actual/README.md).
