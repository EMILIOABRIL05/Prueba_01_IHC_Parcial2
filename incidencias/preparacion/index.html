    Qué demuestra este ensayo
    

    El modelo aplica reglas y permite comparar condiciones de fallo y corrección. Para afirmar que una incidencia se resolvió durante el examen faltan: anunciarla oficialmente, crear un Issue nuevo, implementar el cambio después del anuncio, registrar un commit posterior, probarlo en navegador, conservar evidencia antes/después, revisión de un compañero y defensa individual.
    

    Las pruebas de accesibilidad requieren comprobar foco y lector de pantalla reales. El caso de 320 px requiere medir desplazamiento horizontal en el navegador.
