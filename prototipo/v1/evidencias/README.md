# Evidencias técnicas de v1

`base-zip/IHC-A-01-v1.png` a `IHC-A-12-v1.png` son copias sin editar de las capturas incluidas en `IHC_12_Tarjetas_Completo_Equipo5.zip`, carpeta `evidencias/capturas-tecnicas/`.

El informe técnico de ese ZIP declara generación automática de las capturas el 28 de octubre de 2026. Aquí se conservan como evidencia del material base y no se atribuyen a una ejecución nueva de William, a esta sesión de trabajo ni a participantes externos. No representan necesariamente todos los pasos de cada recorrido.

`procedencia.json` registra para cada archivo su origen y SHA-256, junto con el SHA-256 del ZIP. La suma permite comprobar que las imágenes no fueron alteradas.

Las verificaciones de fuente/lógica de esta rama se documentan en `../VERIFICACION.md`. Para producir capturas nuevas del navegador, ejecutar `../tests/verificar_navegador.py`; los resultados se escriben en una carpeta temporal nueva y deberán revisarse antes de incorporarlos al repositorio.

No hay observaciones humanas, citas, tiempos de participantes ni comparativas de mejora acreditadas en esta carpeta.
